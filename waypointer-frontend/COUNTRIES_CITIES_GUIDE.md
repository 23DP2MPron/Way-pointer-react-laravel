# Новые страницы: Страны и Города

## Что было добавлено:

✅ **Страница списка стран** (`/countries`)
- Показывает все страны мира с флагами
- Фильтрация по регионам (Africa, Americas, Asia, Europe, Oceania)
- Поиск по названию страны
- Информация: столица, регион, население

✅ **Страница деталей страны** (`/countries/:code`)
- Полная информация о стране (флаг, население, площадь, языки)
- Топ-12 самых популярных городов страны
- Карточки городов с градиентными изображениями
- Клик по городу открывает его детали

✅ **Страница деталей города** (`/cities/:id`)
- Информация о городе (население, координаты, регион)
- Краткое описание города
- До 30 главных достопримечательностей
- Клик по достопримечательности открывает модальное окно с:
  - Фото (если доступно)
  - Описание
  - Адрес
  - Категории
  - Ссылка на Wikipedia

✅ **Навигация**
- Добавлена кнопка "Countries" / "Valstis" в Navbar
- Полная поддержка английского и латышского языков

## Как использовать:

1. **Просмотр стран:**
   - Перейдите на `/countries` или нажмите "Countries" в навигации
   - Используйте поиск или фильтр по регионам
   - Кликните на любую страну

2. **Просмотр городов:**
   - На странице страны увидите топ городов
   - Кликните на карточку города
   - Увидите информацию и достопримечательности

3. **Просмотр достопримечательностей:**
   - На странице города кликните "View Details" на любой достопримечательности
   - Откроется модальное окно с подробной информацией

## Используемые API:

- **REST Countries API** - информация о странах (работает без ключа)
- **GeoNames API** - города (требует регистрации)
- **OpenTripMap API** - достопримечательности (требует регистрации)

## Примечание:

Для полной функциональности нужно добавить API ключи в `.env.local`:
```
VITE_OPENTRIPMAP_API_KEY=ваш_ключ
VITE_GEONAMES_USERNAME=ваш_username
```

Инструкции по получению ключей в файле `QUICK_START_API.md`

## Маршруты:

- `/countries` - список всех стран
- `/countries/LV` - детали Латвии (замените LV на любой код страны)
- `/cities/456172` - детали города (ID из GeoNames)

Все страницы полностью переведены на латышский язык!
