# ВАЖНО: Настройка API ключей

## Проблема: Страны и города не отображаются

Для работы страниц Countries и Cities нужны API ключи.

## Быстрая настройка (5 минут):

### 1. GeoNames API (для городов и поиска)

1. Откройте: http://www.geonames.org/login
2. Нажмите "create a new user account"
3. Заполните форму (email, username, пароль)
4. Подтвердите email
5. Войдите в аккаунт
6. Перейдите: http://www.geonames.org/manageaccount
7. Найдите "Free Web Services" и нажмите "Click here to enable"
8. Ваш username - это ваш логин

### 2. Добавьте ключ в проект:

Откройте файл: `waypointer-frontend\.env.local`

Замените:
```
VITE_GEONAMES_USERNAME=your_geonames_username_here
```

На:
```
VITE_GEONAMES_USERNAME=ваш_username
```

### 3. Перезапустите сервер:

```bash
# Остановите текущий сервер (Ctrl+C)
# Затем запустите снова:
cd waypointer-frontend
npm run dev
```

После настройки:
1. Откройте http://localhost:5173/countries
2. Вы должны увидеть список всех стран
3. Откройте http://localhost:5173/cities
4. Попробуйте поиск города (например, "Paris")

2. Перейдите на вкладку Console
3. Посмотрите на ошибки
4. Скопируйте текст ошибки и сообщите мне
